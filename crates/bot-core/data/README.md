# Spanish emoji names

`emoji_es.json` is the Spanish Unicode 17 name table from Python `emoji`
v2.15.0. It preserves the behavior of the retired Python runtime without
requiring Python in production.

- Source: <https://github.com/carpedm20/emoji/blob/v2.15.0/emoji/unicode_codes/emoji_es.json>
- SHA-256: `a485737b37c192e508dfc53282e1e4bfe941bcac8348fa4bdcdbb039b25ef04b`
- License: New BSD License; see `emoji_LICENSE.txt`

The Rust `emojis` dependency owns Unicode sequence recognition. This table is
used only for Spanish display names.
