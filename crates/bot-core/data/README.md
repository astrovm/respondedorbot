# Spanish emoji names

`emoji_es.json` is the Spanish Unicode 18 name table from Python `emoji`
v2.16.0. It preserves the behavior of the retired Python runtime without
requiring Python in production.

- Source: <https://github.com/carpedm20/emoji/blob/v2.16.0/emoji/unicode_codes/emoji_es.json>
- SHA-256: `5c45bb5344ed7ef9ac69acb6861c081815733ce35397b22c2ab5f69a96976912`
- License: New BSD License; see `emoji_LICENSE.txt`

The Rust `emojis` dependency owns Unicode sequence recognition. This table is
used only for Spanish display names.
